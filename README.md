# memory-studio

memory-md 插件所生成记忆文件的**独立查看与编辑工具**。

不做成 DSH 插件的一部分，不引入插件运行时依赖，也不修改插件本身 —— 只是按
`~/.dsh/memory-md/` 的数据格式，提供一个顺手的图形界面，解决「在资源管理器里翻记忆文件不方便」的问题。

## 启动

双击 `start.bat`，浏览器会自动打开 <http://127.0.0.1:7788>。

或者命令行：

```bash
node server.js
```

- 需要 Node.js（本机 v24 已满足），**零第三方依赖**，不用 `npm install`。
- 关闭窗口即退出。

## 数据来源

默认读取 `%USERPROFILE%\.dsh\memory-md`，可用环境变量覆盖：

```bash
set MEMORY_MD_ROOT=D:\other\memory-md
set PORT=8080
node server.js
```

它完全只认这个目录的格式：

```
memory-md/
├── global/                  # 全局记忆作用域
│   ├── MEMORY.md            # 索引：- [标题](memory/xxx.md) — 描述
│   ├── memory/
│   │   └── feedback_xxx.md  # 条目：YAML frontmatter + 正文
│   └── .journal/            # 日记：一天一个文件
│       └── 2026-10-17.md
└── d-workspaces-xxx/        # 各工作区作用域，结构同上
```

日记文件格式（由 `memory_md_journal` 写入，**只读展示**）：

```markdown
# 2026-10-17

## 15:47:30
- 一批留痕
- 又一条

## 16:10:53
- 另一次写入的批次
```

条目文件格式：

```markdown
---
name: 标题
description: 一句话描述
type: feedback        # user | feedback | project | reference
---

正文
```

## 功能

- **浏览**：左侧列出全部作用域（global 置顶，其余按条目数降序），点选查看条目
- **搜索**：顶部搜索框，默认跨全部作用域搜标题 / 描述 / 正文 / 文件名
- **查看**：正文按 Markdown 渲染（标题、列表、代码块、引用、链接）
- **编辑**：改标题 / 描述 / 类型 / 正文，`Ctrl+S` 保存，`Esc` 取消
- **新建**：按 `type + 标题` 自动生成不冲突的文件名，可勾选是否写入索引
- **删除**：二选一 —— 只删索引（文件保留）或索引与文件一起删
- **未索引条目**：允许文件存在但不在 MEMORY.md 里；列表有徽标、可单独筛选、可一键收录/移出
- **移动**：把条目移到其他作用域，重名自动加后缀，索引状态跟随
- **批量**：批量收录 / 移出 / 移动 / 删除（含两种删除方式）
- **新建工作区**：输入本地路径（如 `D:\workspaces\my-proj`）自动推导作用域名
- **索引维护**：主动点击才执行，可整理已有索引或把未索引文件全部收录；平时只做状态标记，不弹窗打断
- **日记查看**（顶栏「记忆 / 日记」切换）：按日期浏览 `.journal/` 的记录，每个 `## 时间`
  批次渲染成时间轴上的一个卡片；支持按周/月筛选、前后翻页、复制当天原文、跨作用域搜索
 
  日记是 **只读** 的 —— 插件本身就把它定位成「只写不读」的留痕，本工具不提供编辑或删除。

任何写操作都会**自动同步 MEMORY.md**，并按「每文件每天最多一份」备份到
`~/.dsh/memory-md/.memory-studio-backup/`。

快捷键：`Ctrl+K` 聚焦搜索，`Ctrl+S` 保存。

## 安全边界

- 只写 `MEMORY_MD_ROOT` 下的内容；作用域名与文件名都做白名单校验，`../`、绝对路径会被拒绝
- 修改前先备份，备份保留原始内容，可手工回滚
- 服务只监听 `127.0.0.1`，不对外网开放

## 注意

这个工具是**绕过 DSH 直接改文件**的。日常的写入仍建议走 `memory_md_save` 工具，
本工具适合做批量整理、比对去重、查漂移这类 DSH 对话里不方便做的操作。
